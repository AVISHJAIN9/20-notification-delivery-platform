Master Checklist (275)

F1-F7: Relational State Ledgers

Nine relational tables powering immutable delivery tracking, versioned templates, user preferences, and lease-based queue states.

F8-F9: Monotonic State Machine

Strict request idempotency with E.164 phone and email normalization, and 4-tier priority preemption (URGENT, HIGH, NORMAL, LOW).

F10: SSTI-Safe Template Engine

Jinja2 SandboxedEnvironment preventing template injection attacks while enabling dynamic conditionals, loops, and language fallback.

F11-F12: Provider Fallback Routing

Polymorphic drivers for Email, SMS segments, and Webhook HMAC-SHA256 with deterministic cost and health failover.

F13-F14: Workers, Backoff & DLQ

Asynchronous workers with token bucket rate limiting, exponential backoff with full jitter, and manual DLQ redrive APIs.

F15: Timezone-Aware Quiet Hours

Enforces quiet hours with midnight wrap-around and rolling 24-hour frequency capping across global timezones with DST.

F16-F18: Security & Zero-Trust RBAC

FastAPI REST API protected by SHA-256 hashed API keys, deny-by-default RBAC, and adversarial multi-tenant data isolation.
